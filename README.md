# tg-ws-proxy

Прокси-сервер для доступа к Telegram в России без VPN.

Утилита организует туннель, превращая стандартное подключение клиента к Telegram API в обёрнутое WebSocket-соединение, которое сложнее заблокировать средствами ТСПУ. Больше не нужно поднимать полноценный VPN.

## Особенности
- 🚀 Работает без VPN и сторонних сервисов.
- 💻 0 пинг: фото/видео отправляються с быстрой скоростью.
- 📱 Работают звонки.
- ⚡ Минимальное потребление ресурсов.
