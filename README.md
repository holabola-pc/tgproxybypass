# tg-ws-proxy

Прокси-сервер для доступа к Telegram в России без VPN.

Утилита организует туннель, превращая стандартное подключение клиента к Telegram API в обёрнутое WebSocket-соединение, которое сложнее заблокировать средствами ТСПУ. Больше не нужно поднимать полноценный VPN на всех устройствах.

## Особенности
- 🚀 Работает без VPN и сторонних сервисов.
- 🔒 Шифрование остаётся нативной частью протокола MTProto.
- 💻 Кросс-платформенность: может работать на сервере, роутере или Raspberry Pi.
- ⚡ Минимальное потребление ресурсов.
